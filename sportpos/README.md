# SportPOS — Zapatillas y ropa deportiva

Punto de venta y posventa para tiendas de zapatillas y ropa deportiva.

## Cómo abrirlo
1. Abra la carpeta `POS-ZAPATILLAS`.
2. Haga doble clic en `index.html` (Chrome o Edge).
3. La primera vez, escriba el nombre de la tienda y cree su usuario. Guarde el código de recuperación.

## Qué tiene
| Pantalla | Para qué sirve |
|---|---|
| Inicio | Lo vendido hoy, la ganancia, la caja y las tallas por agotarse |
| Vender | Buscar o escanear, vender por talla y color, descuento y cobro |
| Ventas | Historial, reimprimir y anular |
| Caja | Abrir, ingresos y retiros, cierre con conteo de billetes |
| Productos | Marca, modelo, talla, color, categoría, precio, costo y stock. Crear varias tallas a la vez e importar desde Excel |
| Inventario | Ingreso de mercadería, tallas por agotarse y movimientos |
| Posventa | Cambios de talla o producto, devoluciones y garantías ligados a la venta |
| Reportes | Ventas, ganancia, categorías y vendedores (ya descuentan la posventa) |
| Configuración | Datos de la tienda, logo, impresora, usuarios y respaldo |

Los precios incluyen IVA. La boleta muestra Neto, IVA (19 %) y Total.
